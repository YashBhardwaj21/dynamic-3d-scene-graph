# Archived `my_desk_sequence` Artifacts

## Overview
This directory contains configuration and benchmark results from the local experiment sequence `my_desk_sequence`.

## When and Why It Existed
`my_desk_sequence` was an early indoor handheld sequence recorded with the Intel RealSense D455 to test offline trajectory estimation, 3D point cloud reconstruction, and object persistence across occlusions.

## Why It Is Archived
It was a specific development test dataset, not a permanent or standard external benchmark. All configuration parameters and evaluation scripts for `my_desk_sequence` have been removed from the live runtime path to prevent dataset-specific branching in production code.
